# 할 일 위젯 (TodoWidget)

Windows 바탕화면 할 일 위젯. 설치 없이 `TodoWidget.exe` 하나로 동작합니다. (Windows 10/11, .NET Framework 4.8 기본 내장)

## 사용법
1. `TodoWidget.exe`를 **계속 둘 폴더**(예: `문서\TodoWidget`)에 넣고 실행
   - 처음 실행 시 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**
   - 첫 실행 때 자동 실행이 등록됨 (exe를 옮겼다면 새 위치에서 한 번 실행하면 경로 갱신)
2. 입력칸에 할 일 입력 후 **Enter**
3. 시간 지정: `내일 오후 3시 회의`, `금요일 2시 반 치과`, `12/24 저녁 7시 파티`처럼 적으면 자동 인식 (입력칸 아래 미리보기, × 누르면 시간 없이 추가). ⏰ 버튼을 누르면 시간 선택기(날짜 칩·달력, 오전/오후·시·분, 빠른 선택, 반복)가 열림 → 일정 **30분 전에 알림**
   - 반복: `매일 9시 영양제`, `평일 9시 반 스탠드업`, `매주 월요일 10시 회의`, `금요일마다 회고`. 반복 일정은 체크하면 다음 회차로 넘어감
4. 동그라미 클릭 = 완료, 마우스 올리면 나오는 × = 삭제(되돌리기 가능), 더블클릭/우클릭 = 수정

## 기능
- 화면: 일력처럼 큰 날짜(토 파랑·일 빨강), 오늘 진행률, "다음 일정" 카운트다운, 지난 일정/오늘/내일/이후/기한 없음 묶음, 완료 접기
- 테마: 밝게 / 어둡게 / Windows 설정 따르기
- 바탕화면 위젯: 제목 부분 드래그로 이동, 가장자리 드래그로 크기 조절, Win+D(바탕화면 보기)에도 유지
- 알림: 오른쪽 아래 팝업 + 소리, 확인 누를 때까지 유지. "10분 뒤 다시 알림" 가능. 컴퓨터가 꺼져 있어 놓친 일정(12시간 이내)은 켤 때 알려줌
- 자동 저장: `%APPDATA%\TodoWidget\todos.json` (백업 `.bak` 유지)
- `⋯` 메뉴 / 트레이 아이콘 메뉴: 항상 위에 표시, 투명도, 알림 시점(5분~2시간 전), 자동 실행 켜기/끄기, 완료 항목 삭제, 위치 초기화, 종료
- `—` 버튼: 트레이로 숨기기 (트레이 아이콘 클릭으로 다시 열기)

## 빌드
```bash
cd src && dotnet build -c Release   # 결과: src/bin/Release/net48/TodoWidget.exe
cd tests && dotnet run              # 핵심 로직 테스트
```
